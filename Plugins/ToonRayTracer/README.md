# ToonRayTracer

UE5.8 のハードウェアレイトレーシング（DXR）を使ったトゥーンシェーダーのプラグイン。
『Ray Tracing in One Weekend』の第11章までをシーンの TLAS 上で実装し、その仕組みの上にトゥーンシェーディングを構築している。

- SceneViewExtension の `SubscribeToPostProcessingPass`（Tonemap）でパスを追加する（トーンマップの後に実行される）
- Renderer の Private ヘッダーは使わず、Public API（`FXRenderingUtils` など）だけで実装している

## 動作条件

- プロジェクト設定でハードウェアレイトレーシングが有効（`r.RayTracing=True`）
- Substrate が無効（`r.Substrate=False`）。滑らかな法線を GBufferA から読むため
- シーンにレイトレーシング用の TLAS が構築されていること。構築されていないフレームでは何もせず元の画像を返す

## 設定パネル

メニューの「ウィンドウ」→「ToonRayTracer」で設定パネルを開ける（エディタ専用モジュール `ToonRayTracerEditor`）。

- 下記のコンソール変数をすべてパネルから変更できる（ドロップダウン、スライダー、カラーピッカー）。変更はすぐ画面に反映される
- 値はプロジェクトのユーザー設定（`Saved/Config/.../EditorPerProjectUserSettings.ini`）に保存され、次回起動時にも引き継がれる
- 「蓄積をリセット」：フレーム間の蓄積をやり直す（レベル上のオブジェクトを動かしたあとに使う）
- 「コンソールの値を読み込む」：コンソールで変更した値をパネルに反映する
- 「初期値に戻す」：すべての設定を初期値に戻す

## 表示モード

`r.ToonRayTracer.ShadingMode` で切り替える。

| 値 | 内容 |
|---|---|
| 3 | トゥーンシェーディング（既定） |
| 0 | 確認用：当たった面の法線を色で表示 |
| 1 | 確認用：本の第9〜11章のマテリアル（拡散反射・金属・ガラス）。ランダムなレイを使うのでノイズが出る |
| 2 | 確認用：Directional Light による N・L のなめらかな陰影 |

`r.ToonRayTracer.TraceMode` で交差判定の対象を切り替えられる。

| 値 | 内容 |
|---|---|
| 1 | シーンのメッシュ（TLAS）に TraceRay（既定） |
| 0 | シェーダー内の解析的な球（本の第11章のシーン。ワールド原点付近に配置）。地面は『The Next Week』第4章のチェッカー、中央の球は第5章の Perlin ノイズによる大理石模様 |

解析的な物体のシーンは `r.ToonRayTracer.AnalyticScene` で切り替える（パネルの「解析的な物体のシーン」）。

| 値 | 内容 | 本のカメラに相当する UE の位置 |
|---|---|---|
| 0 | 本の第11章のシーン（上記） | (-50, 0, 50) 付近から +X 方向 |
| 1 | 『The Next Week』第7章 simple_light。大理石の地面と球を、四角形のライトと球のライトだけで照らす（背景は黒） | (600, 2600, 300) から (0, 0, 200) を見る |
| 2 | 『The Next Week』第7章 コーネルボックス（第6章の四角形で組み立て、天井の四角形のライトだけで照らす。背景は黒） | (-800, 278, 278) から +X 方向 |
| 3 | 『The Next Week』第8章 箱を置いたコーネルボックス（回転・移動した 2 つの白い箱） | (-800, 278, 278) から +X 方向 |
| 4 | 『The Next Week』第9章 cornell_smoke（2 つの箱を黒い煙と白い煙にしたもの） | (-800, 278, 278) から +X 方向 |
| 5 | 『The Next Week』第10章 final_scene の簡易版（地面の箱の格子、ガラス・金属・大理石・中が濁ったガラスの球、全体を包む薄い霧）。オレンジの球は第2章の移動ブラーで動く。1000 個の小さな球の塊は、第3章の BVH（CPU で組み立てた入れ子の箱を、シェーダーでスタックを使ってたどる）で探す。地球の球には、第4章の画像テクスチャで `r.ToonRayTracer.ImageTexture` のテクスチャ（既定は `/ToonRayTracer/Textures/T_EarthMap`）を貼る。見つからなければ UV のチェッカーで代用する | (-600, 478, 278) から Yaw -18.4 度の方向 |

光る物体だけで照らすシーンは、表示モードを「確認用：本の第9〜11章」にすると本と同じ見た目になる。
ノイズが非常に多いため、蓄積フレーム数の上限を 1024 以上、反射回数の上限を 50 にして、しばらく待つ。
トゥーン表示では、光る物体はその光の色で塗られ、それ以外は Directional Light で照らされる。
煙は、トゥーン表示では通る距離から求めた不透明度を 4 段階に区切った「セル画風の霧」として塗る（ノイズが出ない）。
煙の明暗は、煙に入った位置のすぐ先から光源が見えるかで決める。
煙はトゥーンのシャドウレイでは無視する（くっきりした影を落とさない）。

## メッシュごとの設定（Custom Primitive Data）

何も設定しなくても、カメラから見えている面は UE のマテリアルの色（GBuffer のベースカラー）でトゥーンの塗りになる。
メタリックが高くつやのある（ラフネスが小さい）マテリアルは、自動で鏡面反射の金属になる。
Custom Primitive Data は、マテリアルの種類（金属・ガラス）や影色、ハイライトなどを上書きしたいメッシュにだけ設定する。

メッシュの詳細パネルの「Custom Primitive Data」→「Data」に要素を追加して設定する。
使わない項目は 0 のままでよい（0 は「未設定」として扱う）。
`[0]` に種類を指定したメッシュは、`[1][2][3]` の色が UE のマテリアルの色より優先される。

| Index | 内容 | 値の範囲 | 未設定（0）のとき |
|---|---|---|---|
| 0 | マテリアルの種類（1: ランバート, 2: 金属, 3: ガラス） | 0 ～ 3 | UE のマテリアルの色のランバート（反射・屈折の先など GBuffer がない場所では 50% の灰色） |
| 1, 2, 3 | 素材の色（R, G, B） | 0 ～ 1 | 黒（種類を設定した場合） |
| 4 | 金属のぼけ具合（ShadingMode 1 のみ） | 0 ～ 1 | ぼけなし |
| 5 | ガラスの屈折率 | 1 以上 | 1.5 |
| 6, 7, 8 | トゥーンの影色（R, G, B）。素材の色に掛ける | 0 ～ 1 | `r.ToonRayTracer.Toon.ShadowColor` |
| 9 | トゥーンのハイライトの強さ | 0 ～ 1 | ハイライトなし |
| 10 | トゥーンのリムライトの強さ | 0 以上 | リムライトなし |
| 11 | トゥーンの線の太さ（ピクセル）。負の値なら線を引かない | 0 より大きい値 / 負の値 | メッシュの種類ごとの太さ（`OutlineWidth` / `OutlineWidthSkinned`） |
| 12 | `CharacterOnly` のときの扱い。正の値ならトゥーンで塗る、負の値なら通常描画のまま | 正の値 / 負の値 | スケルタルメッシュだけトゥーン |

例：銀色の鏡面の球でハイライトあり → `2, 0.8, 0.8, 0.8, 0, 0, 0, 0, 0, 1, 0`

## コンソール変数

### トゥーンシェーディング（`r.ToonRayTracer.Toon.*`）

| 変数 | 既定値 | 内容 |
|---|---|---|
| `CharacterOnly` | 0 | トゥーンで塗るのをキャラクター（スケルタルメッシュ）だけにし、背景は通常描画（Lumen など）のままにする（鳴潮風のルック）。メッシュごとに Custom Primitive Data の `[12]` で上書きできる。ShadingMode 3（トゥーン）、TraceMode 1（シーン）のときに有効 |
| `Bands` | 2 | 陰影の段階数（2: 影 / 明るい面、3: 影 / 中間 / 明るい面） |
| `ShadowThreshold` | 0.0 | 影との境目の N・L（-1 ～ 1）。上げると影が広がる |
| `LitThreshold` | 0.5 | 中間と明るい面の境目の N・L（Bands が 3 のとき） |
| `EdgeSoftness` | 0.02 | 段階の境目のぼかし幅（N・L） |
| `ShadowColor` | `0.35,0.4,0.6` | 影色（線形の R,G,B）。メッシュごとの設定がなければこれを使う |
| `LightScale` | 1.0 | 明るい面の明るさの倍率（ライトのルクス値は使わない） |
| `CastShadows` | 1 | シャドウレイによる影を付けるか |
| `ShadowBias` | 2.0 | シャドウレイの始点を面から浮かせる距離（cm）。境目に斑点が出たら上げる |
| `ShadowNoiseStrength` | 0.0 | 影の境目を Perlin ノイズで手描き風に揺らす強さ（0 なら揺らさない。0.1 で控えめ、0.3 で強め）。面の向きによる明暗の境目と、シャドウレイの影の輪郭の両方を揺らす |
| `ShadowNoiseSize` | 40.0 | 揺れの大きさ（cm）。メッシュのローカル座標（スケールを掛け戻したもの）で計算するため、カメラや物体が動いても揺れの模様は滑らず、どのメッシュでも同じ大きさの揺れになる |
| `HighlightThreshold` | 0.97 | ハイライトのしきい値（N・H）。1 に近いほど小さい |
| `HighlightStrength` | 1.0 | ハイライトの強さの全体倍率 |
| `RimThreshold` | 0.7 | リムライトのしきい値（1 - N・V）。1 に近いほど細い |
| `RimStrength` | 0.3 | リムライトの強さの全体倍率 |
| `RimLitSideOnly` | 1 | リムライトを光が当たる側だけに出すか |
| `Outline` | 1 | アウトラインを引くか |
| `OutlineWidth` | 1.5 | スケルタルメッシュ以外（背景や小物など）の線の太さ（ピクセル）。0 なら線なし |
| `OutlineWidthSkinned` | 1.0 | スケルタルメッシュ（キャラクターなど）の線の太さ（ピクセル）。0 なら線なし |
| `OutlineThreshold` | 1.0 | 線を引く段差のしきい値（補助レイをずらした量の何倍か）。小さいほど細かい段差にも線が出る |
| `OutlineColor` | `0.02,0.02,0.04` | 線の色（線形の R,G,B） |
| `ReflectionDepth` | 4 | 金属・ガラスで反射・屈折を追いかける回数。0 なら普通の素材として塗る |

映り込みの法線のなめらかさは `r.ToonRayTracer.ReflectionNormalSmoothing`（既定値 15cm）で調整する。
反射・屈折した先で法線を求める補助レイの間隔で、ポリゴン1枚分程度にすると映り込んだ物体の明暗の境目の階段が目立たなくなる（0 なら面ごとの法線）。

### 共通

| 変数 | 既定値 | 内容 |
|---|---|---|
| `r.ToonRayTracer.SamplesPerPixel` | 4 | 1 ピクセルあたりのサンプル数（アンチエイリアス、1 ～ 64） |
| `r.ToonRayTracer.MotionSamplesPerPixel` | 2 | カメラや物体が動いている間のサンプル数（0 なら `SamplesPerPixel` と同じ）。動いている間の負荷を下げ、止まったら蓄積でアンチエイリアスを補う。蓄積しない設定では使わない |
| `r.ToonRayTracer.UseGBufferNormal` | 1 | カメラから見えている面に GBuffer の滑らかな法線を使うか |
| `r.ToonRayTracer.UseGBufferBaseColor` | 1 | マテリアル未指定のメッシュに、UE のマテリアルの色（GBuffer のベースカラー）を使うか |
| `r.ToonRayTracer.UseGBufferForReflections` | 1 | 反射・屈折した先も、カメラから見えている点なら UE のマテリアルの色・滑らかな法線・金属の判定を使うか |
| `r.ToonRayTracer.UseGBufferMetal` | 1 | マテリアル未指定のメッシュを、UE のマテリアルのメタリック（0.5 以上）とラフネスから金属と判定するか |
| `r.ToonRayTracer.SkipMaskedSurfaces` | 1 | カメラのレイが、GBuffer に描かれていない面（マテリアルの透過で抜けた部分など）を通り抜けるか |
| `r.ToonRayTracer.MetalRoughnessThreshold` | 0.4 | 金属として鏡面反射させるラフネスの上限。これより粗い金属は普通の塗りにする |
| `r.ToonRayTracer.Accumulate` | 1 | カメラ静止中にフレームをまたいで結果を平均するか。0 → 1 で蓄積をリセット |
| `r.ToonRayTracer.MaxAccumulatedFrames` | 64 | 蓄積するフレーム数の上限。到達後は新たにレイを飛ばさず結果を表示し続ける（GPU 負荷がほぼ 0 になる）。トゥーン表示はアンチエイリアス分だけで十分なため小さめにしている。ノイズの多い ShadingMode 1 では 1024 程度に上げる |
| `r.ToonRayTracer.DetectMotion` | 1 | 動いている物体を検出し、そのピクセルだけ蓄積をやり直すか（GBuffer の速度と深度の変化で判定） |
| `r.ToonRayTracer.MotionMaxAccumulatedFrames` | 8 | 物体が動いている間の蓄積フレーム数の上限。小さいほど残像が短くなるが、止まっている物体の輪郭もざらつく |
| `r.ToonRayTracer.Debug.Motion` | 0 | 確認用：蓄積をやり直した理由を色で表示する（白：カメラや設定の変更、赤：動いている物体、緑：深度の変化、青：見えている物体・影・反射の先の変化、紫がかった灰色：物体が動いているため蓄積数を抑えている）。全体のリセットの理由はログに出る |
| `r.ToonRayTracer.MaxDepth` | 10 | ShadingMode 1 での反射回数の上限（1 ～ 50） |

`ShadowColor` と `OutlineColor` は文字列型のため、ゲームスレッドで読んでレンダースレッドへ渡している
（文字列型のコンソール変数には `ECVF_RenderThreadSafe` を付けられない）。

## 注意点

- カメラ・表示範囲・上記の設定・ライトが変わると蓄積は自動でリセットされる
- 動く物体は `r.ToonRayTracer.DetectMotion` で検出し、そのピクセルだけ蓄積をやり直す
  - 速度を書き込む物体（可動の物体、アニメーションするスケルタルメッシュなど）が見えているピクセルとその周囲（アウトラインの太さ分）と、
    深度が変わったピクセル（物体が動いて後ろが見えた、など）が対象
  - 物体が動いている間は、ピクセルの中心で「見えている物体・光が届くか・反射した先の物体」を毎フレーム調べ、
    変わったピクセル（動く物体の影が落ちてきた、鏡に映り込んだ、など）だけ蓄積をやり直す
  - それでも残る細かな残像（影の境目の 1 ピクセル幅、ガラスに透けて見える物体など）のため、
    物体が動いている間は全ピクセルの蓄積数を `MotionMaxAccumulatedFrames` までに抑える
  - 影や映り込みだけが変わる場合（ライトの色の変化、画面外の物体の移動など）は検出できない。
    残像が残ったら設定パネルの「蓄積をリセット」を押す（コンソールでは `r.ToonRayTracer.ResetAccumulation` の値を変える）
- シェーダー（`.usf`）だけを変更した場合は、エディタのコンソールで `recompileshaders changed` を実行すれば反映される。
  C++ を変更した場合は、エディタを閉じてからビルドする（Live Coding が有効な間は外部からビルドできない）
- 滑らかな法線と UE のマテリアルの色が使えるのは、カメラから見えている点だけ（反射・屈折の先も、画面内に見えていれば使う）。
  画面外や、手前の物体に隠れている点は、その物体の代表色（これまでにカメラから見えた部分の UE のマテリアルの色の平均）で塗る。
  テクスチャの模様は再現されず、1 色になる。一度も画面に映っていない物体は Custom Primitive Data の色（未設定なら 50% の灰色）になる
- 代表色は物体（GPUScene のインスタンス番号）ごとに最大 4096 個まで覚えておく。
  物体を消したり入れ替えたりしたあとに古い色が映る場合は「蓄積をリセット」を押す（代表色の表も空になる）
- ガラスも影を落とす（シャドウレイでは不透明として扱う）
- マテリアルの透過（Masked）で抜けている部分は、カメラから直接見える場所だけ通り抜ける（GBuffer と比べて判定する）。
  影・映り込み・反射の先では不透明の板として扱われる（AnyHit シェーダーでマテリアルを評価できないため）
